# Запуск

Проект — Angular-приложение. Для запуска нужны Node.js 18.19 или новее и npm.

1. Откройте терминал в папке `lab3`.
2. Установите зависимости:

```bash
npm install
```

3. Запустите сервер разработки:

```bash
npm start
```

4. Откройте в браузере адрес `http://localhost:4200`.

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.
